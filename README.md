## ✨ Features

- 💻 **Live Rust Compiler & Execution:** Run real Rust code directly in the browser powered by the Rust Playground compilation API.
- 📖 **Comprehensive Curriculum:** Step-by-step lessons covering language syntax, ownership rules, borrowing, traits, and concurrency.
- 🎯 **Interactive Quizzes:** Instant concept validation with tailored explanations.
- 📊 **Progress Persistence:** Keeps track of finished lessons in your browser's `localStorage`.
- 🎨 **Developer-First Dark UI:** Tailored dark theme with syntax highlighting, mobile drawer, and quick search.
- ⚡ **Zero Setup Required:** Pure client-side application — learn Rust on any device without local toolchains.

## 📚 Curriculum Overview

1. **Rust Foundations** — Syntax, `let` vs `let mut`, scalar & compound types, functions, and expression returns.
2. **Ownership & Memory Model** — The 3 Golden Rules of Ownership, heap vs stack, moves vs clones, references & borrowing (`&T` and `&mut T`), string & array slices (`&str`).
3. **Structs, Enums & Patterns** — Structs, methods (`impl`), `Option<T>` (the anti-null paradigm), exhaustive `match`, and `if let`.
4. **Error Handling & Collections** — `Result<T, E>`, the `?` try-operator, dynamic arrays (`Vec<T>`), and `HashMap`.
5. **Generics, Traits & Concurrency** — Generic functions, trait bounds, functional iterators & closures, threads, and `mpsc` channel message passing.

## 🛠️ Local Development

Clone and run locally using any static web server:

```bash
git clone https://github.com/personalbotai/rust-learning-path.git
cd rust-learning-path
python3 -m http.server 8080
```

Open `http://localhost:8080` in your web browser.
