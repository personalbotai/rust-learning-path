## ✨ Features

- 💻 **Live Rust Code Runner:** Execute Rust code via in-browser playground execution (`https://play.rust-lang.org/execute`) with fallback sandbox simulation.
- 📖 **15 In-Depth Lessons:** Systematic progression covering memory safety without GC, ownership, borrow checker, traits, and concurrency.
- 🎯 **Deep Technical Quizzes:** Rigorous technical multiple-choice quizzes with detailed Indonesian explanations and architectural insights.
- 🎖️ **Graduation Certificate Generator:** High-resolution Canvas certificate generator with PNG & PDF export — gated strictly to 100% course completion.
- 📱 **PWA & Offline Support:** Service Worker offline caching and Web App Manifest for an app-like mobile experience.
- 💾 **Auto-Resume & State Persistence:** Remembers your exact lesson and completion progress in `localStorage`.
- 🌓 **Adaptive Theme & Mobile UX:** Dark/light mode toggle with expandable animated search and responsive drawer navigation.

## 📚 Curriculum Overview

1. **Fondasi Rust** — What is Rust, variables & mutability (`let` vs `let mut`), scalar & compound types, functions & expressions.
2. **Ownership & Memori** — Golden rules of ownership, move semantics, borrowing & references (`&T` vs `&mut T`), slice fat pointers.
3. **Struktur Data & OOP** — Structs & method implementations (`impl`), `Option<T>` anti-null safety, exhaustive pattern matching.
4. **Error & Koleksi** — Recoverable error handling (`Result<T, E>` & `?`), dynamic vectors (`Vec<T>`), hash maps (`HashMap<K, V>`).
5. **Lanjutan & Concurrency** — Zero-cost generics, traits & trait bounds, lazy iterators & closures, multi-threading & channels (`mpsc`).

## 🛠️ Local Development

Clone and run locally with any static file server:

```bash
git clone https://github.com/personalbotai/rust-learning-path.git
cd rust-learning-path
python3 -m http.server 8080
```

Open `http://localhost:8080` in your web browser.
